Plateforme d'Attack Path Management (APM) conçue selon les standards DevSecOps senior. Transforme les vulnérabilités en un graphe orienté (DAG) interactif, calcule le chemin critique vers la base de données et priorise les points d'étranglement avec simulation de remédiation.

PhishScope-AI

Console CLI d'Analyse Anti-Phishing & OSINT

Console interactive dédiée au triage d'URLs suspectes dans le terminal. Détecte les attaques homographes (Punycode/Cyrillique), le typosquatting (Levenshtein), les redirections et génère une jauge de risque ASCII (0-100) avec recommandations SOC et scans en lot.

Python 100% CLI OSINT Homoglyphes Typosquatting Bulk Triage
Dépôt GitHub

ShadowPot

Honeypot & Moteur de Profilage MITRE ATT&CK

Système de déception interactif multi-services simulant un shell Linux (SSH/Telnet) et un portail d'administration web. Enregistre les frappes, capture les identifiants et cartographie automatiquement les tactiques d'attaque sur le framework MITRE ATT&CK.

Python Deception Tech MITRE ATT&CK Threat Intel HTML Report
Dépôt GitHub
